## Libraries

supaS3 links Rust crates from crates.io under their own licenses, mostly MIT and Apache-2.0. The exact set is recorded in `Cargo.lock`. Notable ones:

| Library | License |
|---|---|
| [GPUI Kit](https://github.com/longbridge/gpui-kit) and GPUI | Apache-2.0 |
| [AWS SDK for Rust](https://github.com/awslabs/aws-sdk-rust) | Apache-2.0 |
| [Tokio](https://github.com/tokio-rs/tokio) | MIT |

Every package carries `THIRD_PARTY_LICENSES.txt`, the full license text of each library in the binary. It is generated by `cargo about` from `about.toml`, which also names the licenses a dependency may have; the build fails when a dependency has any other.
